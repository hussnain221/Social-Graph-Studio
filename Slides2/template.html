Project Overview Member 1Introduction
Part 1 - Problem and idea

SocialGraph Studio turns a social network into a live graph so we can explain BFS and DFS with actual structure, not just textbook diagrams.

Why this project

Graph traversal is easier to understand when students can see the nodes, edges, queue, stack, and visited order move in real time.

  • Shows social network data as a graph.
  • Makes traversal visible and easy to explain.
  • Links theory directly to a working demo.
Member 1 opening section

What the app does

Build, traverse, analyze, and compare.

The app lets us load a graph, edit it manually, choose a source and target, run BFS or DFS, and show the traversal result with live analytics.

This makes it a clean DAA presentation tool for the teacher.

SocialGraph Studio workflow

What to say

  • Users are vertices.
  • Connections are edges.
  • The graph is undirected in this version.
  • Everything runs in the browser.

Breadth-First Search uses a queue. It explores the source first, then the nearest neighbors, then the next layer, which makes it the best choice for shortest social distance in an unweighted graph.

DFS Theory Member 2Stack based search

DFS goes
deep before
backtracking.

Depth-First Search uses a stack. It explores one branch deeply before moving to another branch, which makes it useful for connected components and deep relationship chains.
1

Push

Put the source user on the stack first.

2

Pop

Remove the most recent user from the top of the stack.

3

Visit

Mark the node visited and highlight it in the graph.

4

Push
neighbors

Push unvisited neighbors so DFS keeps diving deeper.

5

Finish

Repeat until the stack is empty. Complexity stays O(V + E).

Limitations And Future Work Member 3Reflection
Part 3 - Final analysis

The current version is strong for classroom learning, but it still has a few limits that we can improve in the next version.

Limitations

  • It only handles unweighted graphs.
  • It focuses on undirected relationships.
  • It does not store data permanently.
Current version scope

Future work

We can add weighted edges, directed graphs, file import and export, and more graph algorithms in a later version.

Possible next release

Why it still works

Even with those limits, the project is still very effective for teaching BFS, DFS, graph modeling, and connected components.
