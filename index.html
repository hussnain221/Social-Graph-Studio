BFS

Breadth-First Search

Time Complexity: O(V + E)

BFS uses a queue (FIFO) and explores the social network level by level. It is best for finding shortest social distance, influence spread, and friends-of-friends discovery. 

BFS(graph, source):
  # Mark source and add to queue
  mark source visited
  enqueue(source)

  while queue is not empty:
    current = dequeue()          # FIFO front

    for each neighbor of current:
      if neighbor not visited:
        mark neighbor visited
        enqueue(neighbor)    # add to rear
DFS

Depth-First Search

Time Complexity: O(V + E)

DFS uses a stack (LIFO) and explores deeply before backtracking. It is best for connected components, deep relationship chains, cycle detection, and community exploration. 

DFS(graph, source):
  # Push source onto stack
  push(source)

  while stack is not empty:
    current = pop()             # LIFO top

    if current not visited:
      mark current visited

      for each neighbor of current:
        if neighbor not visited:
          push(neighbor)       # add to top
